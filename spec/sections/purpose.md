# Purpose Section

## Description
The Purpose section describes what the module does. It is the only **required** section.

## Syntax
```markdown
## Purpose

Description of the module's objective.
```

## Rules
- Must be present in every MAM module
- Should be concise (1-3 sentences)
- Must follow `## Purpose` heading exactly
- Content can be paragraphs or lists

## Example
```markdown
## Purpose

Authenticate users securely using JWT tokens. Supports multiple authentication methods including password-based and token-based flows.
```
