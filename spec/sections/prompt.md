# Prompt Section

## Description
The Prompt section contains LLM instructions and prompts for AI agents.

## Syntax
```markdown
## Prompt

Instructions for the AI agent.
```

## Rules
- Content should be clear and specific
- Use structured format when possible

## Example
```markdown
## Prompt

When using this module:

1. Always validate inputs before processing
2. Return structured JSON responses
3. Log errors with context for debugging
4. Handle edge cases gracefully
```
