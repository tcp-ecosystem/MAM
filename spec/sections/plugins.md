# Plugins Section

## Description
The Plugins section lists required plugins for the module.

## Syntax
```markdown
## Plugins

- @mam/plugin-yaml
- @mam/plugin-mermaid
```

## Example
```markdown
## Plugins

- @mam/plugin-yaml - YAML parsing support
- @mam/plugin-mermaid - Mermaid diagram rendering
- @mam/plugin-python - Python code execution
```
