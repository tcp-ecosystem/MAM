# Basic MAM Examples

This directory contains introductory examples demonstrating core MAM concepts.

## Files

| Module | Description |
|--------|-------------|
| `hello.mam.md` | Minimal "Hello World" MAM module with purpose, rules, and a simple Python function |

## Getting Started

1. Install MAM CLI: `npm install -g @mam/cli`
2. Validate an example: `mam validate examples/basic/hello.mam.md`
3. Execute it: `mam execute examples/basic/hello.mam.md`

## What You'll Learn

- How to write MAM frontmatter (metadata)
- How to define purpose, rules, inputs, and outputs
- How to embed executable Python in a Markdown module
- How to run and validate MAM modules
