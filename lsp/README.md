# @mam/lsp

Language Server Protocol implementation for MAM files.

## Overview

This package provides IDE integration for `.mam.md` files, offering:

- Syntax highlighting
- Autocompletion for MAM directives
- Diagnostics and error reporting
- Go-to-definition support
- Hover information

## Usage

Install as a dependency and connect via LSP client:

```bash
npm install @mam/lsp
```
