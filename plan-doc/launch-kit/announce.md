🚀 **MAM Hub is live — a production module registry for AI systems.**

MAM (Machine Agent Modules) lets you describe intelligent systems in Markdown,
execute them natively, and compile to 16 targets. Today its registry opens:

- 📦 **20 founding modules** — agents, workflows, teams, tools, memory, policies
- 🔍 Search, versioned downloads, SHA-256 integrity on everything
- 🔌 REST + GraphQL + typed client
- 🆓 Free, MIT-licensed, self-hostable in one Docker/file bundle

Editor support is already on OpenVSX (`arkhangellifejiggy.mam-language`).

Start: `mam new agent researcher` → `mam publish` → it's on the Hub.
