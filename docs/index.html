MAM — Markdown as Module

System Description Language whose reference syntax is Markdown

Get Started View on GitHub

Write once, compile to anything

Define your module in a single .mam.md file and compile it to 17+ targets.

my-module.mam.md
# My Module

@version 1.0.0
@author developer

## Variables

- `url` : string = "https://api.example.com"
- `timeout` : number = 30
- `debug` : boolean = false

## Inputs

- `name` : string, required
- `count` : number, default 10

## Functions

### greet

Greets a user by name.

- **param** `name` : string
- **returns** string

```
return "Hello, " + name + "!"
```

### fetch_data

Fetches data from the API.

- **param** `endpoint` : string
- **param** `options` : object
- **returns** object

```
response = http.get(url + endpoint, options)
return response.json()
```

# TypeScript

export const url = "https://api.example.com";
export const timeout = 30;
export const debug = false;

export function greet(name: string): string {
  return "Hello, " + name + "!";
}

export function fetchData(
  endpoint: string,
  options: RequestInit
): Promise<Response> {
  return fetch(url + endpoint, options)
    .then((r) => r.json());
}


# Go

package mymodule

const URL = "https://api.example.com"
const Timeout = 30
const Debug = false

func Greet(name string) string {
    return "Hello, " + name + "!"
}

func FetchData(endpoint string, 
    options map[string]interface{},
) (map[string]interface{}, error) {
    resp, err := http.Get(URL + endpoint)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()
    var result map[string]interface{}
    json.NewDecoder(resp.Body).Decode(&result)
    return result, nil
}

Features

Everything you need to describe systems in Markdown and compile them anywhere.

17

17 Compilation Targets

Python, TypeScript, Go, Rust, Java, C, C++, Ruby, PHP, Swift, Kotlin, and more. One source, many outputs.

📄

Standalone .mam Files

Single-file module definitions using a superset of Markdown. Human-readable, machine-compilable.

🔗

Context Embedding

Embed and compose modules together. Reference other .mam files and build complex system descriptions from simple parts.

🖥

CLI Tools

Powerful command-line interface for initializing, compiling, validating, and managing your MAM modules.

Install MAM

Get up and running in seconds with npm.

$ npm i -g @mam/cli

Quick Start

Create your first module in two commands.

1

Initialize a new MAM module:

mam init my-module
2

Compile it to your target language:

mam compile my-module.mam.md --target python
